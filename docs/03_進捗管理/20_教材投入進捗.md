# 📚 教材投入進捗管理

## 📋 **概要**

ShiftWith本番環境への教材投入の進捗を管理します。中学英文法に特化した質の高い教材を段階的に投入し、ユーザーの学習効果を最大化します。

- **ユーザビリティ問題**: 一般ユーザーによるテスト
