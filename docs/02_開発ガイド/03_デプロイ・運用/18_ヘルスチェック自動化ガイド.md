# 🔍 Supabaseヘルスチェック自動化ガイド

## 📋 **概要**

本番環境のSupabaseプロジェクトが一時停止することを防ぐため、自動化されたヘルスチェックシステムを構築します。

## 🚀 **自動化の仕組み**

### 📅 **スケジュール設定**

#### 1. **毎日の詳細チェック**
- **実行時間**: 毎日午前9時（JST）
- **ファイル**: `.github/workflows/health-check.yml`
- **内容**: 包括的な診断とSlack通知

#### 2. **6時間ごとの軽量チェック**
- **実行時間**: 6時間ごと（1日4回）
- **ファイル**: `.github/workflows/frequent-health-check.yml`
- **内容**: 基本チェックと失敗時のみ通知

### 🔧 **チェック項目**

#### 基本ヘルスチェック
- ✅ Supabase接続確認
- ✅ 教材データ取得テスト
- ✅ レスポンス時間測定

#### 拡張ヘルスチェック
- ✅ 基本接続テスト
- ✅ 教材データ取得テスト
- ✅ 公開教材テスト
- ✅ プロフィールテーブルテスト
- ✅ レスポンス時間テスト（5秒以内）

## 🛠️ **設定手順**

### 1. **GitHub Secrets設定**

GitHubリポジトリのSettings → Secrets and variables → Actionsで以下を設定：

```bash
# 必須設定
PRODUCTION_SUPABASE_URL=https://btakhtivpdhieruediwt.supabase.co
PRODUCTION_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# オプション設定（Slack通知用）
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
```

### 2. **ローカルテスト**

```bash
# 基本ヘルスチェック
npm run health-check

# 拡張ヘルスチェック
npm run health-check:enhanced
```

### 3. **手動実行**

GitHub Actionsページで手動実行可能：
- Actions → Supabase Health Check → Run workflow
- Actions → Frequent Supabase Health Check → Run workflow

## 📝 **カスタマイズ**

### スケジュール変更
```yaml
# .github/workflows/health-check.yml
on:
  schedule:
    # 毎日午前9時（JST）
    - cron: '0 0 * * *'
    # 毎週月曜日のみ
    # - cron: '0 0 * * 1'
```

### チェック項目追加
```javascript
// scripts/enhanced-health-check.js
// 新しいチェック項目を追加
results.checks.newCheck = {
  name: '新しいチェック',
  success: !error,
  error: error?.message || null
};
```
